Expense Tracker

Ứng dụng theo dõi chi tiêu cá nhân/gia đình với đầy đủ tính năng giao dịch, danh mục và báo cáo.

🗄️
Cơ sở dữ liệu
PostgreSQL + pgAdmin
Lưu trữ giao dịch, danh mục, người dùng với hiệu năng cao.
⚙️
Backend
Node.js / Python
REST API xử lý business logic, xác thực và phân quyền.
🌐
Reverse Proxy
Nginx
Load balancing, SSL termination, bảo mật đầu vào.
📡
Monitoring
Prometheus + Grafana
Thu thập metrics, hiển thị dashboard giám sát hệ thống.
📝
Logging
Loki + LogQL
Tổng hợp log tập trung, truy vấn và phân tích lỗi.
🔒
Bảo mật
Hardening
Firewall, HTTPS, JWT auth, rate limiting, input validation.
🐙
Version Control
GitHub
CI/CD pipeline, pull requests, code review workflow.
🖥️
Frontend
HTML / CSS / JavaScript
Giao diện người dùng tương tác, responsive design.

  • ✅ Quản lý giao dịch thu/chi với danh mục linh hoạt
  • ✅ Báo cáo thống kê theo tháng, quý, năm
  • ✅ PostgreSQL làm cơ sở dữ liệu chính + pgAdmin quản trị
  • ✅ Nginx reverse proxy phục vụ frontend + backend
  • ✅ Giám sát hệ thống với Prometheus + Grafana dashboard
  • ✅ Log tập trung bằng Loki + LogQL queries
  • ✅ Bảo mật: HTTPS, JWT, Hardening server
  • ✅ Source code quản lý trên GitHub với CI/CD
